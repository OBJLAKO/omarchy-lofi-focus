## Source review

- `room.rs` normalizes coverage to 0–100 independently of pan, distance and
  volume. A layer without valid finite coverage migrates its former width to
  `coverage = width / 2`, then resets width to 100. Normalizing it again is
  idempotent; saved scenes pass through the same normalization. The discovered
  malformed-coverage case (`null`/invalid string with width 44) was corrected
  to migrate to coverage 22 and width 100, avoiding a second width reduction.
- Material defaults apply to newly created layers: fire/ticks/drops 12, wind
  65, rain/water/noise 100, otherwise 50. Existing saved layers retain their
  migrated values. These are placement defaults, not labels claiming that
  synthesized assets are field recordings.
- `audio.rs` uses four fixed all-pass delay buffers per reusable source slot
  (64 KiB per slot; 16 slots). Feedback magnitudes remain below one; histories
  reset when a slot changes source or sample rate. Processing uses bounded
  samples and normalized parameters, with no new worker, dependency, network
  path or data pack. Parameter transitions are smoothed and settled mixing
  coefficients are cached. The final optimization bypasses the delay lines
  when diffuse gain is zero, clears them once on exit, and expires a true-zero
  input tail after 0.75 seconds at the configured output rate. Silence counters
  reset at that bounded deadline; no new allocation or lifetime owner is added.
  Native regressions cover allocation-free render, smooth entry/exit, tail
  expiry/reactivation and reset across 8–192 kHz.
- Coverage describes stereo width and diffusion. At the middle setting a
  centered stereo source at full legacy width preserves its original stereo
  frame; a mono source receives decorrelation as coverage increases. Migrating
  saved levels does not promise identical old mono waveforms. This is not
  HRTF, individualized headphone rendering, front/back localization or true
  360-degree audio. Pan remains an independent control.
- `engine.rs` accepts solo listening only for an enabled, running ambience
  source while playing. It mutes the other runtime gains, retains the selected
  source's normal level/master/duck/distance behavior, and does not boost it.
  The original eight-second deadline is controller state, not a saved preference or a
  scene field; its command returns before persistence. Pause/stop, transport,
  valid scene application, preference reload, selected-source removal/failure
  and expiry clear it. Invalid scene references are validated before clearing
  preview or changing saved settings. The decoder-failure cancellation case
  was added after review.
- Solo transitions preserve the shared room buses. A short existing reverb or
  echo tail may remain while other direct sources fade down; this is intentional
  room continuity. Controller gain checks alone do not establish acoustic
  peak/RMS behavior, so the native signal regressions and silent real-output
  run are separate checks.

on that page. No measurement data or additional dependency was added here.
