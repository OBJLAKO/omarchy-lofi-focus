# Skylofi 3 launch artwork

Generated on 2 October 2026 with the built-in image_gen tool. The hero is launch
artwork composed from references, not a raw application screenshot. The GIFs
beside it capture the actual QML components with isolated public demo data.

Inputs: the release Listen, Mix and Settings screenshots (`preview.png`,
`docs/redesign/mix.png`, `docs/redesign/settings.png`) from release commit
`5586dc93b87bae6730320bb225c978b9fded5fd6`, before the 3.0.1 polish. The old
`preview.png` reference is replaced by the generated cover in the new package.
Output: `skylofi-v3-cover.png`. `skylofi-v3-social.jpg` encodes the same image at
its original 1774 × 887 dimensions for GitHub's under-1-MiB upload limit.

sober dark blue-gray styling; do not invent features or redraw a different app.
Arrange all three screenshots as clean upright floating panels, with Listen and
Mix most legible and Settings secondary. Give them enough breathing room and
subtle shadows. Background: quiet dark charcoal with a subtle warm copper/Rust-
toned ambient glow and refined thin wave contours, no photo, no confetti, no
cartoon mascot, no fake desktop or browser chrome. Main exact typography:
“Skylofi 3”. Secondary exact typography: “Your listening space. Now powered by
Rust.” Small accurate feature line: “Radio · YouTube · Nature mix”. Optional
small badge exact text “Rust backend”. Typography should be editorial, crisp and
sophisticated, avoid promotional hype and fake performance claims. Everything
should be balanced and readable at GitHub thumbnail scale. This is an actual
release 3 launch, not a conceptual UI design. No star counts, no invented
testimonials, no platform endorsements, no watermarks. Natural negative space.
High quality.
